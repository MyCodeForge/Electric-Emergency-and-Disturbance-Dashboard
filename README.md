#   Electric Emergency and Disturbance Dashboard - Portfolio Project (Frontend Focus)

##   Purpose

   This project, the "Electric Emergency and Disturbance Dashboard," was undertaken as a personal initiative to showcase my skills and abilities in **Frontend Development**. It serves as a tangible demonstration of my proficiency in building user interfaces and handling data presentation within a web application.

   Beyond the functional application itself, this project aims to highlight:

   * **Frontend Capabilities:** My ability to design, develop, and implement a user-friendly and interactive web interface.

   * **Workflow and Development Process (Frontend):** A glimpse into my structured approach to frontend development, including planning, implementation, and attention to detail in the user experience.

##   Project Overview (Frontend)

   The Electric Emergency and Disturbance Dashboard features a user-friendly interface built with Vue.js. It takes data (provided as an array of JSON objects) and presents it in a meaningful and insightful way through interactive visualizations.

   The key components of the **frontend** application include:

   * **Frontend:** A modular interface built with Vue.js. It utilizes Chart.js to create interactive visualizations of the outage data.
